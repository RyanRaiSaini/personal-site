# Ryan Rai Saini — Personal Site

My portfolio, set inside a real-time 3D football stadium. I'm a Mathematics student at the University of Waterloo looking for software engineering, AI and data internships and co-op roles. Every part of the ground is a section of the site: the goal is my projects, the dugout is my experience, the dressing room is my skills.

**Live site:** https://ryansaini.vercel.app

## Highlights

- **A stadium built to scale in Blender.** Four tiers, 63,322 seats, aisles, entrances, a truss roof with sliding panels and a ring of screens, all generated by Python scripts (`blender/`) from one file of measurements, then packed into a 1.7 MB model. The surfaces and the sky are photographed materials from Poly Haven.
- **Light worked out ahead of time.** Blender answers the expensive questions once (where does the roof's shadow fall, how much sky can each seat see) and stores the answers on the model, so a laptop gets soft, correct shade for almost nothing.
- **The roof is the dark-mode switch.** Closing the retractable roof switches the site to its dark theme and brings the floodlights up. Left alone, the roof follows Brampton: shut at night and in rain or snow.
- **Live from Brampton.** Day or night follows Brampton's real clock, and the weather comes from Open-Meteo. If it is snowing there, it snows through the open roof here.
- **My GitHub contributions on a scoreboard.** An LED board hung under the main stand's second tier shows the year's contributions, the best day and the last 16 weeks, read from GitHub's public calendar and refreshed hourly.
- **It stops drawing when nothing moves.** The 3D picture is drawn every frame only while something is in motion or you are doing something, 30 times a second for a while after, and then not at all. Measurements are in [docs/redesign/PERFORMANCE.md](docs/redesign/PERFORMANCE.md).
- **A camera tour with real addresses.** Each section has its own URL (`/projects`, `/skills`…) and its own page of real text, so it can be linked, searched and read by a screen reader. The 3D view flies between them.
- **A flat "match view".** Phones, browsers without WebGL and anyone who prefers plain pages get the whole site as one scrolling page, told as a match from kick-off to full time.
- **Easter eggs.** Seven of them. Try the ball on the far penalty spot.
- **Adapts to the device.** Three quality levels (shadows, glow, resolution) chosen from the hardware and lowered automatically if the frame rate drops. Motion is switched off for visitors who ask their device for less of it.

## Project structure

```
app/
├── data/
│   ├── portfolio.ts      # every word on the site
│   ├── resume.ts         # the résumé, as data
│   └── photos.ts         # photo captions and album order
├── sections/registry.ts  # the list of sections and where each lives in the stadium
├── components/
│   ├── sections/         # the content of each section (one file each)
│   ├── ui/               # header, panel, icons
│   ├── world/            # the page shell: tour or match view, live data, sound, name tags
│   ├── world3d/          # the 3D world
│   │   ├── stadium/      # the stadium model, its materials and light, seats, pitch, goals
│   │   ├── rooms/        # dressing room, trophy room, press room, ticket office, mixed zone
│   │   ├── players/      # the players, their moves and the goal scripts
│   │   ├── atmosphere/   # sky, lights, weather
│   │   ├── camera/       # the camera rig, the start screen's view and the walk-out
│   │   └── spots.ts      # camera positions for every section
│   ├── match/            # pieces of the flat match view
│   └── resume/           # the résumé page
├── api/                  # weather and GitHub contributions
├── lib/                  # sun position, clocks, sound, shared store
├── match/page.tsx        # the flat match view
└── <section>/page.tsx    # one small page per section
blender/                  # the scripts that build the stadium model in Blender
public/stadium/           # the model, the seat positions, textures and sky the site loads
scripts/                  # model packer, texture fetcher, screenshots, measurements, photos, résumé PDF
docs/redesign/            # the redesign: findings, model comparison, assets, before and after
```

**Changing something?** [WHERE-TO-EDIT.md](WHERE-TO-EDIT.md) lists every piece of the site and the file it lives in.

## Running locally

Requires Node.js 22 or newer.

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

Other scripts:

```bash
npm run build      # production build
npm run lint       # ESLint
npm run typecheck  # TypeScript
npm run resume     # rebuild the résumé PDF from app/data/resume.ts
npm run photos -- "<folder>"   # shrink photos into public/photos
npm run shots -- http://localhost:3000 <folder>   # a fixed set of screenshots
npm run measure -- http://localhost:3000          # frame rate and processor load on this machine
npm run stadium:build && npm run stadium:pack     # rebuild the stadium model (needs Blender)
```

## Deployment

Every push to `main` is linted, type-checked and built by GitHub Actions, and deployed to Vercel.
